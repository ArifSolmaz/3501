Reproducibility

Public rerun path for the audit and source manifest.

The current public reproducibility level is a numerical and archive-source audit. The scripts are designed for the full analysis environment where the cached result products exist.

Public materials

  • Selected pre-analysis figures.
  • Numerical audit JSON.
  • MAST/JWST query JSON.
  • Audit and archive-query scripts.
  • Reviewer information and project-update pages.

Run the public scripts

python3 scripts/audit_numerical_claims.py
python3 scripts/query_primary_sources.py

query_primary_sources.py performs metadata queries and avoids large downloads by default. Detector-level JWST reruns should use exact archive products selected from the manifest and a pinned JWST/CRDS environment.
