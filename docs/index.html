Purpose

A public, inspectable route through the pre-analysis.

Scientific claim

Starspot occultations and unocculted active regions can shift apparent transit mid-times at the seconds-to-minutes level. Those shifts can contaminate TTV, orbital-decay, apsidal-precession, and ephemeris-update work when activity is not modelled or flagged.

Method stance

The project is not framed as a blind correction machine. It develops a decision framework: correct when justified, inflate uncertainty when correction is underdetermined, and exclude transits when the morphology makes timing unreliable.

Public use

This site serves the application-stage public package and can become the accepted-project hub for code releases, validation products, corrected ephemerides, publications, and progress notes.
