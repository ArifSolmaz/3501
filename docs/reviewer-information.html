Reviewer route

A compact path from project claim to inspectable evidence.

This page summarizes the scientific claim, evidence level, hard cases, and planned public updates for reviewers and collaborators.

Scientific claim

Starspot occultations and unocculted active regions can introduce apparent transit mid-time shifts at the seconds-to-minutes level. These shifts can mimic or contaminate TTV, orbital-decay, apsidal-precession, and ephemeris-update analyses if they are not explicitly modelled or flagged.

The proposed work develops a decision framework rather than a black-box correction: it asks when correction is justified, when uncertainty inflation is more defensible, and when a transit should be excluded.

Evidence level in the current public package

  • Numerical consistency checks for the main pre-analysis timing claims.
  • Cross-method timing comparison across the four timing validation systems.
  • MAST, Lightkurve, and JWST archive-source manifests.
  • Selected pre-analysis figures.
  • Scripts that reproduce the audit inside the full local analysis environment.

What to check first

  1. RMS timing values and cross-method agreement.
  2. HAT-P-36b, the hard validation case.
  3. Injection-recovery result and limitations.
  4. MAST/JWST source manifest and raw reanalysis path.
  5. Domain-gap and reproducibility notes.

Scientific caution

HAT-P-36b is the important caution case because method spread is larger than in HAT-P-11b, WASP-19b, and WASP-52b. This does not weaken the central activity-timing motivation; it defines the boundary where the proposed decision framework must become more conservative.
