Open science

Reusable code, documented examples, and public project outputs.

The project is designed to produce open, reusable materials for active-star transit timing: software modules, example notebooks, selected data products, corrected ephemeris tables, and publication-linked releases.

Planned public outputs

  • Open-source Python modules for simulation, detection, correction, and reporting.
  • Example notebooks for selected active-star systems.
  • Representative simulation subsets and metadata tables.
  • Corrected timing and ephemeris tables where validation criteria are met.
  • Versioned releases connected to papers, conference material, and project updates.

Licensing and reuse

Project text, documentation, and generated figures are intended for CC BY 4.0 reuse unless a file states otherwise. Project code is intended for MIT-licensed release. Third-party mission data remain governed by their archive and provider citation rules.
